# ClipRemote.Mobile

Cliente Android dedicado al Oppo.

La primera versión tendrá una sola pantalla:

- dirección del PC;
- token de emparejamiento;
- conectar/desconectar;
- botones `Undo` y `Redo` para validar el recorrido completo;
- después se sustituirá por el panel de animación.

El móvil mantendrá una conexión WebSocket local con `ClipRemote.Agent` mientras el panel esté abierto.

No se usará voz, nube ni servicios externos.
